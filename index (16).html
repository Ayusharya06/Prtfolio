Projects

Real-world problems I've solved through code.

🤖 AI / Productivity
ThumbAI — AI Thumbnail Regenerator
Web App  ·  2024
⌨️ React · Claude API · Canvas API

Problem: YouTubers and content creators waste hours redesigning entire thumbnails just to change one small element — a background, a text label, or a product image. There was no tool that let you surgically replace only the part you wanted.

Solution: Built ThumbAI — a web app where creators upload a thumbnail, select a specific region using a canvas-based selection tool, describe what they want replaced, and Claude AI regenerates only that element while keeping the rest of the thumbnail intact. Cuts thumbnail iteration time from hours to seconds.

🔔 Key Features
✅Canvas-based region selector — click and drag to isolate any element in the thumbnail for AI replacement.
✅Claude API integration for intelligent, context-aware image element regeneration based on text prompts.
✅Non-destructive editing — only the selected region changes, preserving brand identity and composition.
✅One-click export — download the final edited thumbnail at full resolution, ready to upload.

📱 Android / Productivity
FocusLock — Penalty-Based App Blocker
Android App  ·  2024
⌨️ Android · Java · Accessibility API

Problem: Traditional app blockers are easy to bypass — users just uninstall them or disable them when willpower runs out. Students and professionals lose hours daily to distraction apps like Instagram and YouTube with no real consequence for unlocking them.

Solution: Built FocusLock — an Android productivity app that locks distracting apps during focus sessions and introduces a penalty system for early unlocks. Users set a focus goal; if they break it, they must complete a challenge (math problem, long press timer, or a donation to a cause) before accessing the blocked app. Makes distraction costly enough to avoid.

🔔 Key Features
✅Accessibility API-based real-time app monitoring — detects and intercepts launches of blocked apps instantly.
✅Penalty unlock system — users face timed challenges or math problems before they can access a blocked app mid-session.
✅Session scheduling — set daily focus windows (e.g. 9am–12pm) with automatic block/unblock cycles.
✅Focus streak tracker — visualizes daily consistency to build long-term discipline habits.
